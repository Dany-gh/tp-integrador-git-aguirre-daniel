# Sitio: Pasos usados en Git y GitHub

## Descripción

Se quiere dejar plasmado en una pagina HTML los pasos que se deben seguir para crear un repositorio local
usando git y luego subirlo a GitHub, usando un repositorio Remoto.
Tambien como se crea una rama nueva, el uso de Issue y Pull Request ambos en GitHub.  

## Objetivo

Se quiere dejar en el historial todos los cambios y modificaciones que se realizan en el archivo html, css de la carpeta proyecto.
Ademas de los cambios en los archivos ENTREGA.md y README.md

## Estructura del repositorio

El sitio tiene como carpeta principal el directorio tp-integrador-git-aguirre-daniel.
En el mismo tenemos la carpeta proyecto y los archivos README.md y ENTREGA.md
Dentro de la carpeta proyecto tenemos dos archivos.
index.html y styles.css.
Index.html tenemos los pasos que tenemos que seguir para trabajar con git y crear un repositorio local y remoto.
Poder seguir los diferentes archivos que tenemos en el directorio principal.
